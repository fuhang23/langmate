## 0. 一句话定位

**一个「AI native 的英语学习搭子」**——有教学法、有长期记忆、有人格（亦师亦友）的对话式学习伙伴。从新托福口语起步，逐步扩展到全英语学习，以 CEFR 度量水平。

## 1. 已完成（当前 MVP 基线）

### 口语三大模式（全部落地）

| 模式 | 状态 | 说明 |
|---|---|---|
| 跟读复述（Listen and Repeat） | ✅ 完成 | 阶段A：41 场景 287 句入库、逐句播放/复述/整句判分、仪表盘刷新 |

### 基础设施

- **TTS**：豆包语音合成大模型（`en_female_myra_cmb_uranus_bigtts`）
- **ASR**：硅基流动（临时方案，待换豆包 ASR）
- **发音评测**：有道智云（音素级）
- **LLM**：DeepSeek（内容四维评分 + 教学对话）
- **进度存储**：SQLite `practice_records` 表 + 学习仪表盘
- **题库**：跟读 41 场景 / 面试 39 主题 / 聊天场景库（结构化入库，非 RAG）

| 功能 | 说明 |

- **规划与督学引擎**：每日任务、主动提醒、遗忘曲线复习、周期复盘
- **陪伴层**：情绪共情、低压力环境、适度仪式感

## 3. 建议推进顺序

1. **核心表达收藏**（独立、简单，快速补齐面试闭环）
2. **跟读精细判分**（强化口语护城河）
3. **豆包 ASR 替换**（独立任务，已与全双工解绑）
4. 之后分流：**扩展科目**（听力/阅读）或 **产品化底座**（账号 + 记忆）

> 注：全双工实时语音已于 2026-08-20 决定放弃（Web 端回声消除成本高、边际收益低，「按住打断」已覆盖核心体验）。

---

## 4. 关键风险与约束

- **版权**：本地资料（果实托福/青山学堂等）自用无碍，商用前须解决授权。
- **评分权威性**：AI 评分须如实标注「参考分」，不冒充官方。
- **单用户架构**：多账号是架构级改动，需在扩展前想清楚。

> 已排除的风险：全双工实时语音（回声消除）——因成本收益不匹配已放弃，不再作为目标。
