## 0. 一句话定位

**一个「AI native 的英语学习搭子」**——有教学法、有长期记忆、有人格（亦师亦友）的对话式学习伙伴。从新托福口语起步，逐步扩展到全英语学习，以 CEFR 度量水平。

### 基础设施

- **LLM**：DeepSeek（`services/llm/deepseek.py` 的 `chat_json`，判分 / 判断 / 打标 / 教学对话）
- **Embedding**：阿里云百炼 embedding + faiss 本地索引
- **TTS**：豆包语音合成大模型（`en_female_myra_cmb_uranus_bigtts`）
- **ASR**：硅基流动（长期方案，豆包 ASR 替换已取消）
- **发音评测**：有道智云（音素级）
- **进度存储**：SQLite `practice_records` 表 + 学习仪表盘（六模块进度模型 `SECTIONS`）
- **题库**：跟读 41 场景 / 面试 39 主题 / 聊天场景库 / 写作两题型（结构化入库，非 RAG）
- **存储**：SQLite 多库（corpus / ingest / dedup / toefl_favorites / toefl_writing_favorites / toefl_progress）+ faiss 向量索引

## 4. 关键风险与约束

- **版权**：本地资料与采集内容（果实托福/青山学堂等）自用无碍，商用前须解决授权（`ingest_records` 已保留 `source`/`url` 供溯源）。
- **评分权威性**：AI 评分须如实标注「参考分」，不冒充官方。
- **单用户架构**：多账号是架构级改动，需在扩展前想清楚。
- **大模型误判**：采集的考试/广告判断与去重（纯 embedding 判据）均可能误判，预览人工确认是唯一把关；去重阈值取高、倾向漏判而非误判。

> 已排除的风险：全双工实时语音（回声消除）——因成本收益不匹配已放弃，不再作为目标。
