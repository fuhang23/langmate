# 题目收藏与练习统计 · 实现文档

> 功能定位：为四种题型（听后复述 / 互动面试 / 邮件写作 / 学术讨论写作）的每一道题增加【收藏】星标与【练习次数】统计，选题页与题库管理页显示练习徽章，并支持按收藏状态（不限 / 未收藏 / 已收藏）与练习状态（不限 / 未练习 / 已练习）筛选。
> 本文记录完整实现细节，供后续维护与迭代参考。

---

## 一、功能概述

```
判分事件（跟读每句 / 面试每题 / 写作每次）→ practice_records 落库（带题目标识）
  → 选题页 / 题库管理页展示：
      星标收藏（乐观更新） + 练习徽章（跟读「已练 N/7 句 · 共 M 次」/ 面试「已练 N/4 题 · 共 M 次」/ 写作「已练 M 次」）
      筛选：收藏 [不限/未收藏/已收藏] + 练习 [不限/未练习/已练习]（与关键词搜索 AND 叠加）
```

核心价值：题库可自主标记与追踪——收藏重点题反复练、筛「未练习」补盲区、「已收藏」快速回访。

---

## 二、产品决策（2026-08-22 确认）

| 决策点 | 结论 |
|---|---|
| 计数与展示 | **判分事件入库 + 覆盖数展示**：每条判分记录带题目标识落库；卡片展示覆盖数 + 总次数 |
| 覆盖界面 | **选题页 + 题库管理页**：三个练习播放器选题页与题库管理页统一加星标 / 徽章 / 筛选 |

**补充设计决策：**
- 「已练习」判定：跟读 / 面试 covered > 0（组内任一句 / 题练过即算）；写作 count > 0
- 题目标识统一 `question_key`：`repeat:{scenario_id}` / `interview:{topic_id}` / `writing:{question_id}`，由**后端**拼接（前端只传 id）
- agent 对话链路（`analyze_speech_tool.py`）无题目上下文，维持现状（question_key 空，不参与统计）
- 历史练习记录无题目归属，不追溯；新记录起算

## 三、数据流

**练习统计（判分 → 落库）：**

| 链路 | 补传内容 | 落库 |
|---|---|---|
| 跟读 | 前端 `onAudioReady` 传 `scenario_id + sentence_seq` → WS 信封 → `score_repeat(scenario_id, sentence_seq)` | `question_key="repeat:{scenario_id}", question_seq={seq}"` |
| 面试 | 前端 `onTranscript` 传 `topic_id + question_seq` → WS 信封 → `score_interview(topic_id, question_seq)` | `question_key="interview:{topic_id}", question_seq={seq}"` |
| 写作 | 前端已传 `question_id` → `writing_score_ws` 透传 → `score_writing(question_id)` | `question_key="writing:{question_id}"` |
| agent 对话 | 不传（无上下文） | `question_key=""`，不参与统计 |

**收藏：**
```
选题页/管理页星标 → question_favorite.add/remove {question_key}（mutation）
  → QuestionFavoriteStore（INSERT OR IGNORE 幂等 / DELETE）→ 前端 Set 乐观翻转（失败回滚）
```

## 四、数据存储

### 4.1 `practice_records` 加两列（幂等迁移）

```sql
ALTER TABLE practice_records ADD COLUMN question_key TEXT NOT NULL DEFAULT '';
ALTER TABLE practice_records ADD COLUMN question_seq INTEGER NOT NULL DEFAULT 0;
CREATE INDEX idx_records_question_key ON practice_records(question_key);
```

迁移方式：`_init_schema` 内 `PRAGMA table_info` 检查后 `ALTER TABLE`（老库自动迁移）；`idx_records_question_key` 索引**在补列之后**创建（顺序依赖）。

### 4.2 新表 `question_favorites`（独立 db：`data/toefl_question_favorites.db`，环境变量 `LANGMATE_QUESTION_FAVORITES_DB` 覆盖）

```sql
CREATE TABLE IF NOT EXISTS question_favorites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    question_key TEXT NOT NULL UNIQUE,
    created_at TEXT NOT NULL
);
```

与表达级收藏（`favorites` / `writing_favorites`）职责分离：这里收藏的是「题目本身」。

## 六、后端接口

**WS 信封（submodule `repeat_score_ws.py` / `writing_score_ws.py`）：**

- `repeat_score` 信封新增可选字段 `scenario_id` / `sentence_seq`（int 校验，默认 0）
- `interview_score` 信封新增可选字段 `topic_id` / `question_seq`
- `writing_score` 信封已有 `question_id`，新增透传给 `score_writing`
- 旧前端不传新字段时默认 0，question_key 为空不参与统计（向后兼容）

**HTTP（submodule `ws_http.py`）：**

| action | path | 类型 | payload/响应 |
|---|---|---|---|
| `question_favorite.add` | `/api/toefl/question/favorite/add` | mutation | `{question_key}` → `{status:"added"}` |
| `question_favorite.remove` | `/api/toefl/question/favorite/remove` | mutation | `{question_key}` → `{status:"removed"}` |
| — | `/api/toefl/question/favorites` | GET | `{keys: [...]}` |
| — | `/api/toefl/question/stats` | GET | `{stats: {question_key: {count, covered}}}` |

## 八、使用方式

1. 选题页（跟读 / 面试 / 写作）：点卡片右上角星标收藏 / 取消；卡片显示练习徽章；用「收藏」「练习」两组胶囊筛选（与搜索叠加）。
2. 练一道题（判分成功即计数）：跟读每句判分各记 1 次，回选题页徽章实时更新（重新进入页面时刷新）。
3. 题库管理页：同样可星标 / 看徽章 / 筛选；切题型 tab 重置搜索与筛选。
4. 筛选语义：「已练习」= 练过任意部分（跟读 / 面试 covered>0；写作 count>0）；「未收藏」= 无星标。

## 九、已知限制与风险

1. **历史记录无题目归属**：新功能上线前的 practice_records 不参与题目统计（question_key 空）；仪表盘 section 聚合不受影响（含历史记录）。
2. **数据同步时机**：收藏 / 统计在页面挂载时拉取；练习后回选题页（组件重挂载）即刷新；选题页与题库管理页之间不同页实时同步（进入时各自拉取）。
3. **写作判分失败不计次**：仅 LLM 判分成功路径落库（与现有行为一致）。
4. **agent 对话练习不计入题目统计**（无题目上下文，仍计入仪表盘 section 聚合）。
5. **卡片 button→div 改造**：保留了 role/tabIndex/onKeyDown 键盘可达性与全部样式类。
