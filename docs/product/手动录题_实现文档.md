# 手动录题 · 实现文档

> 功能定位：让用户手动录入 2026 新托福四种题型（口语「听后复述」「互动面试」、写作「邮件写作」「学术讨论写作」）进入题库，与内容采集共用题库与去重基础设施。
> 本文记录完整实现细节，供后续维护与迭代参考。

---

## 一、功能概述

```
内容采集页 → 切到「手动录题」tab → 选题型 → 填动态表单
  →（可选）AI 生成参考内容 / 自动断句 → 提交
  → 去重检测（重复则提示，可强制）→ 写入 corpus.db + 同步去重向量
```

手动录题是「内容采集」（粘贴链接/上传文件）之外的第三种入库方式，三者并列于内容采集页顶部 tab。

---

## 二、产品决策（2026-08-22 确认）

| 决策点 | 结论 |
|---|---|
| 入口 | 内容采集页第三个 tab「手动录题」 |
| 句数/题数 | 严格对齐考试：听后复述固定 7 句、互动面试固定 4 题 |
| 意群断句 | 可选手动填（`/` 分隔），留空则系统自动按意群断句（大模型） |
| 去重 + AI 辅助 | 提交时走去重（重复提示可强制）；参考范文/回答可选，AI 辅助生成也作为可选接口 |

---

## 三、四种题型的录入字段

| 题型 | 必填 | 可选 |
|---|---|---|
| 听后复述 | 场景标题、7 句英文（text） | 场景引导语、每句意群断句（chunks，`/` 分隔） |
| 互动面试 | 主题标题、4 题英文题（prompt_en） | 主题描述、每题中文要点/参考回答/核心表达 |
| 邮件写作 | 标题、题目（prompt_en：收件人+场景+任务） | 中文翻译、参考范文 |
| 学术讨论写作 | 标题、题目（prompt_en：教授提问+同学观点） | 中文翻译、参考范文 |

## 四、数据存储

手动录题复用现有 `corpus.db` 表，无新增表：
- 写作 → `writing_question`（task_type=email/discussion）
- 听后复述 → `repeat_scenario` + `repeat_sentence`
- 互动面试 → `interview_topic` + `interview_question`

去重复用 `data/dedup.db` 的 `question_embedding` 表（入库后同步题干向量）。

## 五、后端模块（`app/services/manual/`）

| 文件 | 职责 |
|---|---|
| `generate.py` | `generate_reference(category, payload)`：AI 生成参考范文/回答 + 核心表达；`chunk_sentences(sentences)`：听后复述意群自动断句 |
| `add.py` | `add_manual_question(category, payload, force=False)`：校验 → 自动断句 → 转 items → 去重 → 入库 → 同步向量 |

### 5.1 校验规则（add.py）

- category 必须在四种题型内。
- 听后复述需恰好 7 句、互动面试需恰好 4 题（否则报错）。
- 标题、题干（prompt_en）为必填，缺失报错。

### 5.2 去重与强制

- 提交先 `detect_question_duplicates`，重复且未 `force` 返回 `{status:"duplicate", similarity}` 不入库。
- 用户确认后带 `force=true` 再提交，则强制入库。
- 入库后 `sync_question_embeddings` 同步题干向量，供后续采集/录题去重复用。

## 八、使用方式

1. 进入「内容采集」→ 切到「手动录题」tab。
2. 选择题型（听后复述/互动面试/邮件写作/学术讨论写作）。
3. 填写表单（必填项：标题 + 题干/句子/问题）。
4. 可选点「AI 生成参考」（写作/面试生成范文与回答，复述提供自动断句）。
5. 点「提交录入」，若命中重复会弹确认「疑似重复 xx%，是否强制录入」。
6. 确认后入库完成，可在对应练习模块看到新题。

## 九、已知限制与风险

1. **去重为单条/单组**：每次手动录入一个场景/主题/题目，去重以该单元为粒度，与采集的混合粒度一致。
2. **AI 生成失败降级**：`generate_reference` / `chunk_sentences` 失败时由前端捕获展示错误，不阻断手动填写提交。
3. **自动断句为整句兜底**：LLM 断句失败时降级为「整句作为一个 chunk」。
4. **核心表达格式**：前端以逗号/换行分隔的字符串输入，提交时转数组。
5. **幂等**：入库复用 `add_*` 的 title 去重，重复提交不会产生重复数据。
